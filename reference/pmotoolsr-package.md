# pmotoolsr: Toolkit for working with Portable Microhaplotype Objects (PMOs)

Read, write, validate, process, build, and combine Portable
Microhaplotype Object (PMO) files in R. See the README and the function
reference for details, and note the 0-based (on disk) to 1-based (in R)
index convention.
